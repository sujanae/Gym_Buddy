# Gym Buddy 🏋️‍♂️

A Flutter-based **offline gym workout tracker** that lets you log your workouts with date, time, exercises, and notes. All data is stored locally using **Hive**, so no internet or external database is required.

---

## Features

- Add new workout entries with:
  - Date of workout
  - Time of workout
  - List of exercises performed
  - Optional notes
- Edit existing workouts
- Delete workouts
- Offline storage with **Hive** (no backend required)
- Future-ready for adding features like:
  - Tags (e.g., Chest, Leg Day)
  - Search and filter
  - Progress tracking
